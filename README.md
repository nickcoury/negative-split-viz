# Negative-split research — interactive workbench

Static visualization site for an in-progress research project on **pacing in
24-hour and 100-mile ultramarathons**: how rare negative and even splits are
among elite performers, and whether world-class efforts are paced more evenly.

**This repo is generated.** It is a publish target — the analysis pipeline,
source archives and methodology live in a separate private repository, and
this mirror is overwritten on each publish. Please don't send PRs here.

Data is aggregated from public results (DUV Ultramarathon Statistik, timing
companies such as RaceResult and Breizh Chrono, and organizers' own published
lap files). Every performance traces back to a source URL in the underlying
dataset.

Findings shown here are **preliminary and subject to revision.**
